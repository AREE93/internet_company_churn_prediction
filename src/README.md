# Source Code

This directory contains reusable Python code for the Interconnect Customer Churn Prediction project.

## Files

### preprocess.py

Contains functions related to:

- Data cleaning
- Date conversion
- Feature engineering
- Data preparation
- Feature transformations

### predict.py

Contains functionality related to:

- Loading the trained model
- Preparing new customer data
- Generating churn predictions
- Obtaining churn probabilities

## Purpose

The goal of this directory is to separate reusable production-oriented code from exploratory analysis performed in the Jupyter notebook.

The code can later be extended to support model deployment through an API.
