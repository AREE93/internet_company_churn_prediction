# Power BI Dashboard

The Power BI dashboard was developed to communicate the results of the churn prediction model and provide actionable insights for customer retention.

## Dashboard Overview

The dashboard includes the following analysis areas:

### 1. Model Overview

This section presents the main performance metrics of the selected Machine Learning model, including:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

### 2. Churn Risk Analysis

This section analyzes the distribution of predicted churn probabilities and customer risk levels.

The objective is to identify customers with a high probability of leaving the company and support the prioritization of retention strategies.

### 3. Customers at Risk

This section focuses on customers with a higher predicted probability of churn.

The analysis can be used to support targeted retention campaigns and prioritize intervention efforts.

### 4. Feature Importance

This section presents the variables that have the greatest influence on the churn prediction model.

The most important features include:

1. TotalCharges
2. TenureMonths
3. MonthlyCharges
4. Type
5. InternetService

## Technologies

- Power BI
- Python
- LightGBM

## Purpose

The objective of the dashboard is to transform Machine Learning predictions into business insights that can support customer retention and decision-making.
